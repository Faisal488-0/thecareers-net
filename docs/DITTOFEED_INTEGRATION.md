# Dittofeed integration

Dittofeed is kept as an isolated Git submodule under `tools/dittofeed` and is not part of the website runtime bundle.

Use it for TheCareers engagement workflows such as email/notification journeys, candidate follow-up, reminders, and event-driven messaging. Keep provider credentials outside GitHub and connect it to TheCareers only through authenticated APIs/webhooks after a separate deployment.
