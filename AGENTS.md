# Agent instructions

Before UI, scraping, job-matching, analytics, CRM, chatbot, or 3D work, read `.agents/skills/project-toolbank/SKILL.md`.

Use the toolbank selectively. Prefer the existing TheCareers pipeline first, then add optional tools behind adapters or feature flags. Do not add a heavy dependency simply because it is available. Keep secrets server-side, preserve source verification, retain audit/emergency-stop controls, and keep the current approved dashboard/globe behavior unless the user explicitly requests a redesign.
